# Proyecto: GenerarCuenta

 ### Descripción:
### Descripción:
Este proyecto solicita el nombre, apellido y contraseña del usuario, valida sus datos y muestra la información en pantalla si son correctos o no.
--
## Analisis:

---
### Entrada:
- `Nombre` = valor,
- `Apellido` = valor,
-  `Contraseña` = valor.
---

### Procesamiento:
#### Contraseña es de mayor o igual que 8 caracteres y no contiene nombre del usuario 
---
### Salida
#### Usuario: valor, Contraseña: valor.
---
